# 🃏 원카드 클럽 (One Card Club)

친구와 링크/방 코드로 만나 즐기는 **실시간 온라인 원카드**입니다. PC와 휴대폰 브라우저를 지원합니다.

## 주요 기능

- 2~6인 비공개 방, 6자리 방 코드, 초대 URL 복사
- 닉네임으로 입장 및 준비/시작, 게임 종료 후 재대결
- 서버가 모든 카드/턴을 판정: 내 패만 확인 가능, 다른 사람은 남은 카드 수만 표시
- 실시간 턴 동기화, 방 채팅, 60초 턴 제한 및 자동 드로우
- 새로고침해도 동일 브라우저에서 세션 복원
- 모바일/데스크톱 반응형 디자인
- **Node.js 20 이상만 필요**합니다. npm 패키지 설치가 필요 없습니다.

## 컴퓨터에서 실행

1. [Node.js](https://nodejs.org/) 20 이상 설치
2. 압축을 푼 폴더에서 터미널 실행
3. 다음 명령 실행:

   ```bash
   npm start
   ```

4. 브라우저에서 `http://localhost:3000` 열기
5. 같은 와이파이의 다른 기기는 컴퓨터 내부 IP로 접속할 수 있습니다. 외부 친구와 게임하려면 아래처럼 인터넷에 배포하세요.

검증용 테스트:

```bash
npm test
```

## 친구들이 인터넷으로 접속할 수 있도록 배포 (Render 예시)

> 이 ZIP은 **소스 코드**입니다. 주소가 인터넷에 공개된 상태는 아닙니다. 아래 배포 절차를 마쳐야 친구들도 접속할 수 있어요.

1. GitHub에서 새 저장소 생성 후 이 폴더의 **파일과 `public`, `test` 하위 폴더**를 업로드합니다. `server.js`, `package.json`은 저장소 최상위에 둡니다.
2. [Render](https://render.com/)에 로그인 → **New → Web Service** → GitHub 저장소 연결.
3. 설정을 다음처럼 지정합니다.
   - **Language / Runtime:** Node
   - **Build Command:** `echo "No dependencies"`
   - **Start Command:** `npm start`
   - **Health Check Path:** `/health`
   - 플랜은 제공되는 옵션 중 선택합니다. 비용 및 무료 플랜 제공 여부는 Render 정책을 확인하세요.
4. **Deploy Web Service**를 누른 뒤 Render가 발급한 `https://...onrender.com` 주소에 접속합니다.
5. 게임방을 만들고 **초대 링크 복사** → 카카오톡 등으로 친구들에게 공유하면 됩니다. 친구들은 자기 닉네임으로 접속 후 **준비 완료**, 방장은 **게임 시작**을 누릅니다.

`render.yaml`도 들어 있으므로 Render Blueprint 방식도 사용할 수 있습니다. 다만 플랜별 제한은 배포 시점에 확인해 주세요.

> **주의:** 게임방은 서버 메모리에만 보관됩니다. 서버가 재시작/절전되면 방, 채팅, 카드 진행 상태가 초기화됩니다. 장기 운영하거나 상시 방 보존이 필요하면 Redis/데이터베이스에 상태 저장 기능을 추가해야 합니다. 무료 호스팅에서는 슬립 후 복귀에 시간이 걸릴 수 있습니다.

## 이 버전의 원카드 규칙 (하우스 룰)

- 각자 7장, 같은 **무늬 또는 숫자/문자** 1장씩 낼 수 있습니다. 못 내거나 원하면 1장 뽑고 턴 종료.
- **2: +2 / A: +3 / 검은 조커: +5 / 빨간 조커: +7**. 공격 중에는 다른 공격 카드로 누적 가능. **3** 카드를 내면 공격 방어 가능 (현재 무늬 관계없이).
- **7 또는 조커:** 원하는 무늬 지정. 조커는 어떤 무늬에서도 낼 수 있습니다.
- **J:** 방향 반전 / **Q:** 다음 플레이어 건너뛰기 / **K:** 한 번 더 턴 진행.
- 카드 한 장이 남으면 **원카드!**를 외쳐야 합니다. 다음 플레이어의 카드 행동 전에 다른 사람이 잡으면 2장을 추가로 뽑습니다.
- 한 턴 60초, 제한 시간 초과 시 자동으로 1장 (공격 중엔 누적 장수) 뽑고 넘깁니다.
- 손에 든 카드를 **모두 먼저 내면 승리**입니다.

원카드는 지역/모임마다 규칙이 다르므로, 위 규칙을 미리 합의해 두세요.

```text
├── render.yaml

```

## 운영 시 참고

- SSE(Server-Sent Events)로 게임 상태를 즉시 전달하고, HTTP POST로 행동을 전송합니다. 브라우저가 연결이 끊어지면 자동 재접속합니다.
- 게임 상태는 연결한 사용자에게 맞게 제공됩니다. 다른 사람의 비공개 카드, 토큰은 전달하지 않습니다.
- 이 프로젝트는 소규모 지인 간 게임용입니다. 공개 서비스로 확대하려면 계정/인증, 요청 속도 제한, 지속 저장소, 모니터링 등을 추가하는 게 좋습니다.
- 기존 사용자가 URL에 포함된 방 코드와 자신의 브라우저 세션 토큰으로 재접속할 수 있지만, 링크만 받은 다른 사람은 진행 중인 게임에 중간 합류하지 못합니다.
